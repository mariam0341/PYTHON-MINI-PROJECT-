# 🎮 Number Guessing Game

## Description
This is a Python Number Guessing Game created as a mini project.

## Concepts Used
- Variables
- Input Function
- Conditional Statements
- While Loop
- Random Module
- Functions

## How to Run
1. Open the project in VS Code.
2. Run:
   python number_game.py
3. Guess the number between 1 and 100.
4. Play again if you want.
